# Supply Chain & Shipment Analytics

A Python-based supply chain analytics project that combines shipment and supplier data to analyze operational performance, shipment delays, costs, and supplier risks.

## 📊 Dataset

* **20,000** shipment records
* **2,000** supplier records
* Integrated using `supplier_id`

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Matplotlib

## 🔍 Key Features

* Shipment performance analysis
* Supplier performance & risk analysis
* Delayed shipment analysis
* Freight cost analysis
* Customs & weather delay analysis
* Carbon footprint analysis
* KPI generation and reporting

## 📁 Project Output

Cleaned and integrated datasets with analytical summaries and KPIs for further project integration.
